## 本轮修复验证

- multipart 上传覆盖单次请求继承的 Content-Type，boundary 与实际请求体首尾一致，共享 Session 默认头保持不变。
- 未支持沙盒的接口在获取凭证前拒绝，凭证服务不可用或缓存为空时也不发生额外请求。
- 新旧登录、get/post/fetch 及获取应用凭证使用统一的域名映射；路径前缀正确，映射不会重复应用。
- HTTP 错误保留根级、嵌套和网关通用业务码及对应消息；没有业务码、或响应为列表/字符串时仍按 HTTP 错误抛出。
- 11 项专项回归及原有 44 项测试均通过；没有跳过或标记预期失败。
